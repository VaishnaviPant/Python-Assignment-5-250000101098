## Overview

This repository contains the Python programs prepared for **Assignment 5** as part of the B.Tech Computer Science Engineering coursework.

The assignment consists of 50 Python programs covering file handling and file operations in Python.

These programs demonstrate how to create, open, read, write, append, copy, search, modify, rename, and delete files. They also cover file modes, file pointer operations, file-related functions, directory handling, and the use of the `os` module.

Each program is organized according to its respective question number for easy identification and execution.

---

## Topics Covered

The assignment focuses on the following Python programming concepts:

1. **File Handling Basics** – Opening and closing files in Python.
2. **Reading Files** – Using `read()`, `readline()`, and `readlines()`.
3. **Writing to Files** – Using `write()` and `writelines()`.
4. **Appending Data** – Adding new content to existing files.
5. **File Modes** – Understanding `r`, `w`, `a`, `r+`, `w+`, and `a+`.
6. **File Pointer Operations** – Using `tell()` and `seek()`.
7. **File Content Processing** – Counting characters, lines, words, vowels, digits, and special characters.
8. **Searching in Files** – Searching for words and displaying matching lines.
9. **File Manipulation** – Copying, merging, reversing, and converting file contents.
10. **File Information** – Checking file existence and retrieving file details.
11. **OS Module** – Renaming files, deleting files, and creating directories.
12. **Directory Operations** – Listing filenames and checking file or directory paths.

## Execution Instructions

### Prerequisites

- **Programming Language:** Python
- **Python Version:** Python 3.8 or higher
- **Code Editor:** Visual Studio Code (VS Code)
- **Dependencies:** No external libraries are required. The programs use Python's built-in functions and standard library modules, including `os`.

### Steps to Run

1. Install Python on your system.
2. Open the assignment repository in Visual Studio Code.
3. Open the terminal in the repository directory.
4. Execute the required Python file using:

```bash
python Q01.py
```

On systems where Python 3 is invoked separately, use:

```bash
python3 Q01.py
```

Replace `Q01.py` with the required question file, such as `Q02.py`, `Q03.py`, or any other question number.

Programs that require user input will prompt for the necessary information in the terminal.

### Important File Handling Notes

- Programs that read existing files require the specified text file to be available in the correct directory.
- Use the correct filename and file path while executing file-related programs.
- Write mode (`w`) creates a file if it does not exist and overwrites its existing contents.
- Append mode (`a`) adds content to the end of an existing file without removing its previous contents.
- Read mode (`r`) requires the file to exist.
- Some programs create, rename, or delete files and directories. Check the specified paths before executing them.
- Programs that copy, merge, or modify files may require separate source and destination files.
